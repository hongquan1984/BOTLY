## 3. Evaluated & Rejected / Deferred Sources

### H. Cozy RPG Inventory Icons (Lui Gevorgyan)
- **URL:** [https://lui-gevorgyan.itch.io/cozy-rpg-inventory-icons](https://lui-gevorgyan.itch.io/cozy-rpg-inventory-icons)
- **Evaluation:** Pay-what-you-want on itch.io. Direct automated CLI downloads are restricted by Itch's dynamic token/CSRF architecture. 
- **Disposition:** Replaced cleanly by Nieobie (CC0) and Game-icons.net (CC BY 3.0) vector items (backpack, bowl, apple, herbs, shoes, lotus, book, chest), which provide full vector scalability across desktop and mobile without raster blur.

### E. Caz Pixel Fantasy RPG
- **URL:** [https://cazwolf.itch.io/caz-pixel-free](https://cazwolf.itch.io/caz-pixel-free)
- **Evaluation:** Pixel art style.
- **Disposition:** Excluded per project design rule: *"Không biến UI thành game pixel retro - Không được trộn lẫn các phong cách icon khiến giao diện thiếu nhất quán."* HealthClues uses high-resolution handpainted scenes (`sleep-valley-handpainted.webp`) and modern fantasy vector art; retro pixel art creates severe visual jarring.

### F. Cozy Fantasy RPG UI — Free Sample (ZSS Game Lab)
- **URL:** [https://zss-game-lab.itch.io/cozy-fantasy-rpg-life-crafting-ui-free-sample](https://zss-game-lab.itch.io/cozy-fantasy-rpg-life-crafting-ui-free-sample)
- **Evaluation:** Commercial game license allowed, but redistribution requires sample tiers.
- **Disposition:** Kenney Fantasy UI Borders (CC0) and our CSS/SVG parchment frames provide complete, zero-dependency border coverage.
