# Floating Fantasy Village 3D

An interactive, mobile-friendly 3D miniature fantasy village diorama suspended high above the clouds, built with React 18, TypeScript, Vite, and Three.js.

## Key Features

- **Cozy Miniature Diorama:** High-altitude floating island with a natural rocky underside, lush green plateau, cobblestone pathways, and turquoise mountain lake.
- **Real Medieval 3D Architecture:** 17 authentic 3D GLB buildings and props with upgraded warm PBR materials, glowing windows, and lanterns.
- **Playable 3D Character:** Rigged traveler model with smooth skeletal animations (`Idle`, `Walk`, `Run`).
- **Obstacle-Avoiding Navigation:** Intelligent click/tap-to-move pathfinding using an A* grid with collision clearance and line-of-sight smoothing.
- **5 Interactive Destinations:** Lumi's House, Knowledge Library, Herbal Garden, Peaceful Lake, and Village Square with custom camera framing and interactive modal dialogs.
- **Isometric Perspective Camera:** Smooth orbit rotation, zoom, distance and pitch clamps to prevent going underground or losing the island, plus a one-click camera reset.
- **Performance & Mobile First:** Adaptive pixel ratio, scalable shadow maps, Low/Medium/High quality presets, and live FPS/draw-call monitoring.
