## Required response contract

Return only JSON matching `App/tester/review.schema.json`. Supply exactly one check for each required ID. `PASS` requires current-run direct evidence (command and outcome, live URL and action/result, or an inspected image path). `FAIL` requires a reproducible observed defect. Use `UNVERIFIED` when the environment or evidence does not support a conclusion. Cite actual paths/URLs/viewport/test output in `evidence`; keep it empty only for UNVERIFIED. For each non-PASS check, state the exact issue or missing evidence in `finding`.

`prompt_for_antigravity` must be a self-contained, actionable Vietnamese prompt: affected screen/flow, reproduction, expected behavior, files or components to inspect, acceptance criteria, and focused regression tests. If only external blockers remain, ask Antigravity to stop and report them rather than invent data. If all checks pass, state that the local playable scope is accepted and list any separate release gates in `release_readiness`. Never request deployment, commit, push, production data changes or content approval by a model. `next_test` names the exact next useful test.
